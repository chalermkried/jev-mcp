Jev model by TypeSafe ↗

01 Bring two keys

  1. Request access to this server.

    Contact the owner through the repository for an MCP access token. The Bearer token is required on every /mcp request.

    Authorization: Bearer <MCP_ACCESS_TOKEN>

  2. Use your own Jev API key.

    Get your key from TypeSafe. Send it in the header below for every tool call. Jev usage is billed to your account.

    X-Jev-Api-Key: <YOUR_JEV_API_KEY>

02 Connect your client

MCP configuration / JSON
{
  "mcpServers": {
    "jev": {
      "url": "https://YOUR_HOST/mcp",
      "headers": {
        "Authorization":
          "Bearer <MCP_ACCESS_TOKEN>",
        "X-Jev-Api-Key":
          "<YOUR_JEV_API_KEY>"
      }
    }
  }
}

Replace both placeholders in your client. Use Streamable HTTP with custom headers; keep your keys private.
